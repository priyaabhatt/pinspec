# The UI lives in a shadow root, with Tailwind compiled to px

pinspec draws its toolbar and card on other people's pages, so its UI (React, Tailwind, shadcn/ui) is mounted in a shadow root on a host element with `all: initial` and the maximum z-index, and its theme variables sit on `:host`, not `:root`. Two Tailwind behaviours break inside a shadow root, so `build/postcss-shadow-safe.js` fixes them at build time: every `rem` becomes `px` (a page with `html { font-size: 62.5% }` would otherwise shrink pinspec), and `@property` rules become plain declarations in the first cascade layer (they are ignored in shadow roots, which breaks rings and shadows; unlayered, the declarations would override every utility instead). Radix portals are pointed at the shadow container instead of `document.body`. Don't remove the PostCSS plugin or switch to an iframe without revisiting this.
